# 研一上学期工作总结

作为技术总结的第一篇文章，本文旨在对研一上学期的核心工作进行全面复盘。开启记录计划的核心驱动力在于：我需要借由高频的文字总结，来系统性地锻炼自己的写作总结与逻辑表达能力，并以此为杠杆，提升接下来的科研生产力。

6月到9月是一个过渡阶段，这段时间我适应了本科生到研究生的转变，这时候还没有分方向，主要在打基础和师兄打一些研究生的竞赛。主要回顾了ROS基础，然后学习了高翔老师的《视觉SLAM十四讲》的前六章，和《点云库PCL从入门到精通》的前12章，了解到PCL库中的ICP配准较慢，参考学习了高翔老师一个手搓版的ICP速度非常快。

10月开始确定了研究方向，开始阅读相关论文，主要学习了怎么去读文献和复现算法，开始了解了领域内的优秀论文，主要以经典的点云滤波为主。

在其中学习了LIOSAM和liosan的变种liorf，其中关于IMU预积分的内容参考了《自动驾驶中的SLAM》

## 一、 核心科研攻关：恶劣天气激光雷达滤波算法 (SCDF)

本阶段确立了贯穿整个学期的核心研究痛点，并完成了从发现问题到重构框架的完整科研闭环。

| 研发环节     | 详细工作内容与核心突破                                       |
| :----------- | :----------------------------------------------------------- |
| **痛点剖析** | 复现 LIDROR、DSOR 等前沿算法，结合自定义 DBscan 聚类实测，发现核心矛盾：低反射率物体（如黑色车辆）极易被误判为尘点或雪雾噪点。 |
| **框架重构** | 摒弃传统算法对雷达线束（ring）字段的强依赖，解决固态雷达无法泛化的问题；重构 LiDARDustX 数据集标签，建立二分类 Precision / Recall / F1 评估体系。 |
| **算法创新** | 提出融合“强度、密度、一致性、球形度”等多维特征的加权评分机制；引入基于密度的聚类修正模块，配合 $z$ 值接地约束、救援模块与远场抑制，针对性解决黑车误检。 |
| **工程优化** | 引入 Optuna 贝叶斯优化框架，以“F1 最大化”和“耗时最小化”为双目标进行自动化参数寻优。 |
| **量化成果** | 在 ly150 子集上，算法 **F1 分数达 70.54%**（大幅优于 LIOR 的 39.94% 与 LIDROR 的 36.35%）；接入下游 LIO-SAM 任务后 ATE / RPE 精度显著提升；已完成小论文骨架搭建。 |

## 二、 SLAM 定位建图与点云底层开发

脱离对开源库的重度依赖，深入底层数学原理与框架源码，提升了 C++ 编程功底与算法落地能力。

| 技术方向          | 详细工作内容与核心突破                                       |
| :---------------- | :----------------------------------------------------------- |
| **底层配准算法**  | 脱离 PCL 官方库依赖，基于高斯牛顿法迭代求解刚体变换，**从零手写 ICP 点云配准库**；引入 C++17 并行算法加速最近邻搜索与雅可比计算，实测匹配速度反超原生 PCL。 |
| **SLAM 二次开发** | 深入 LIO-SAM 框架，新增“增量式地图扩建”功能，通过设计“有效特征点比率”实现对全局地图更新的动态管理，并完成仿真验证。 |
| **点云工具链**    | 开发多地图坐标系统一工具，利用 SVD 求解刚体变换对齐两张地图，并针对 GPS 原点偏差问题确立了基于 ICP 粗配准的迭代方案。 |
| **前沿论文追踪**  | 剖析 M-detector 的三种遮挡机制及球面深度图像帧间变化建模，跑通作者数据集并对其真实实时性（标称 87ms/帧）进行了量化评估。 |

## 三、 机器人自主导航系统工程

聚焦于软硬件系统集成与经典路径规划算法的实车部署。

| 任务模块         | 详细工作内容与核心突破                                       |
| :--------------- | :----------------------------------------------------------- |
| **系统全栈搭建** | 基于先锋机器人 P3-DX，独立攻克驱动配置、单线雷达接入、TF 坐标系变换树缺失、代价地图无消息等系统级底层问题。 |
| **环境地图构建** | 使用 gmapping 算法在真实场景下完成了走廊及 204 室的二维栅格地图构建，为后续导航提供高精度静态先验。 |
| **规划算法联调** | 自主复现 $A^*$ 全局路径规划算法，并将其封装为 ROS 的 `move_base` 插件；与 DWA 局部规划器进行深度联调，成功在实体机器人上跑通绕障与自主导航任务。 |

## 四、 现存挑战与下阶段规划

| 待解决问题领域     | 现象剖析与下阶段工作计划                                     |
| :----------------- | :----------------------------------------------------------- |
| **科研论文冲刺**   | SCDF 小论文的理论框架已完备。下阶段核心任务是补充下游实车实验、优化对比图表设计，完成论文最终润色并投递。 |
| **动态避障优化**   | 导航重规划时，内部地图数据未能同步更新实时障碍物。计划深入 `move_base` 底层代价地图更新逻辑，提升动态避障响应能力。 |
| **建图鲁棒性增强** | LIO-SAM 定位发生漂移时极易污染全局地图。计划引入位姿协方差置信度检测机制，从源头阻断错误点云并入全局地图。 |
